# 2027 過年南洋之旅・行程規劃

純 HTML／CSS／JS，沒有建置步驟。資料來源：`pages/family-trip/plan.html`（2026-11-11 版）。**目前是 `travel-planner/` 內的成品，尚未發布，`pages/family-trip` 沒動。**

## 啟動
```
cd files/travel-planner
python3 -m http.server 8765
# 開 http://localhost:8765/
```
地圖圖磚、字型（Huninn）和 Leaflet 走網路 CDN；離線時地圖退回嵌入地圖／外部連結。

## 旅程資料
- `data/trip.json` 是唯一來源（行程、每日照片與小提醒、費用、匯率、用品）。**請 AI 改行程時，改 `trip.json` 並把 `rev` 加 1**；舊的本機草稿會被取代（要保留請先「匯出 JSON」）。
- 行程欄位：`id, date, start, dur(分), cat, name, addr, lat, lng, cost{amount,cur,basis,est}, note, locked`。`lat/lng` 為 `null`＝座標未查到，不在地圖上顯示。`cost: null`＝金額未填（不計入）。
- `days[日期]`：每日標題、人數、照片（`img/`，含作者與授權）、小提醒。`general`：全程出發前提醒。`routes`：路段覆寫（`hide:true`＝該段已由行程本身表示，不另列）。
- 照片取自 `plan.html` 每天配的那幾張，保留 CC 作者標註；「示意」照片不是該日實景。

## 這一版的處理規則
1. **時間一律用新加坡時間**（＝台灣時間）。巴淡島（印尼，慢 1 小時）的當地時間寫在各行程備註。
2. **費用一律輸入整團總價，「每人」金額先不顯示**（人數另議）。標「估」＝尚未預訂或價格訂前再查；沒有數字的（年夜飯、用車、按摩等）金額留空，不估價。
3. 幣別 TWD／SGD／MYR／IDR；匯率是**參考估值**（open.er-api.com 2026-11-13），出發前請更新。
4. 首選住宿用 Montigo 3 晚（2/9 搭已訂的 BR216 回）；萬豪 Harbour Bay 備選、2/10 回程方案、夜間動物園備選寫在備註。
5. 路段時間是兩點直線距離 ×1.3 的估算（只估時間、不估費用）；計畫書有寫明的段落（步行、車程分鐘數）用 `routes` 覆寫。
